# 영웅

영웅마다 파일 하나를 만든다. 파일 이름은 `영웅이름.md`다.

- 확정된 영웅은 아직 없다.
- 프로토타입에 나오는 임시 창술사는 여기에 적지 않는다. (사용자 지시, 2026-11-15)
- 영웅, 이름, 외형, 스킬 구성은 전부 오리지널로 만든다. 다른 게임의 캐릭터를 옮겨 오지 않는다.

## 영웅 문서에 적을 것
- 이름, 직군, 사거리 (앞뒤 순서를 정한다. [03-영광의리그.md](../03-영광의리그.md))
- 역할: 탱커, 이동기, 끌어오기, 광역 딜러, 힐러, 버퍼 중 무엇인지
- 평타와 스킬: 효과, 범위 모양, 마나 소모, 시전 중 끊기는지
- 특성과 전용보물 ([05-성장과편성.md](../05-성장과편성.md))
- 외형과 모션 메모
- 각 항목의 상태 표시: `[확정 날짜]`, `[가정]`, `[미정]`
